# BIST Portföy Karar Terminali

GitHub Pages + GitHub Actions ile çalışan statik dashboard.

- CVKMD
- ALTINS1
- ASTOR
- KTLEV

GitHub Actions her 30 dakikada bir Borsa İstanbul sembollerinin Yahoo Finance chart geçmişini çeker ve RSI, SMA20/50/200, MACD, hacim, momentum ve relatif güç üzerinden 0–100 AL/BEKLE/SAT skorlarını yeniden hesaplar.

> Not: Bu veri kaynağı resmi Borsa İstanbul gerçek zamanlı veri akışı değildir; gecikmeli/günlük olabilir. Yatırım tavsiyesi değildir.

## Pages
Repo Settings → Pages → Source: GitHub Actions.
